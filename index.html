what's inside

Built for the voice loop.

Every layer was tuned around the specific failure modes of running a voice frontend against a streaming agent CLI on a noisy desktop mic.

Custom "halo" wake word

Single-word wake trained on 188 ElevenLabs voice samples + 524 negatives. F1 = 0.80. Ships in the repo — no training step on first install. silero-VAD gate (vad_threshold=0.7) on top of the DNN kills false fires on room noise. Falls back to hey_jarvis if the file is missing.

Persistent Claude session

One long-lived claude -p --input-format stream-json process per session, reused across every turn. No more per-turn subprocess spawn, no more exit None race. Each follow-up speaks the same session ID (Mercury, Neptune...).

Watch-Claude popup

A separate PowerShell window opens per session, live-tailing ~/.halo/runtime/<agent>.log. Text deltas, tool calls, result events all stream there so Halo's main terminal stays clean. Toggle with AGENT_CLI_VISIBLE.

Noise suppression pipeline

Three layers: mic RMS noise gate, silero-VAD gate on the wake DNN, faster-whisper internal vad_filter=True. Plus a residual hallucination filter for distil-whisper's "Thank you" artifacts on silence. Plus mic-mute during Halo's own TTS — no feedback loop.

Fuzzy fallback dispatcher

When the router LLM is unreachable AND your transcript mentions an agent name (even a Whisper-mangled "Cloud" for "Claude"), Halo dispatches to that agent directly instead of giving up. AgentConfig.fuzzy_triggers is per-agent and extensible.

Live dashboard

Auto-opens at http://127.0.0.1:7070 on startup. Pipeline visualization, live transcript, session panel with green/yellow/red agent connection chips, recent files (click to open), reset/clear controls, event log polled at 4 Hz.

Voice-mode permissions

Claude runs with --permission-mode bypassPermissions; Codex with -c approval_policy="never". You can't click "approve" by voice, so both agents are pre-configured to never prompt. Verified against official Claude Code + OpenAI Codex CLI docs.

halo doctor

Read-only diagnostic. Probes Ollama (HTTP), each agent's --version, Kokoro model files. Prints [ok]/[warn]/[fail] per dependency with the exact install command for any miss. Run after install to verify your environment.

open stack

Every layer is open source.

No proprietary glue. Swap any layer; the contract between them is plain stdin/stdout.

get running

Installed in six commands.

Python 3.11+. NVIDIA GPU recommended (RTX 3060 is plenty); CPU paths exist. 

# 1. install the package
pip install git+https://github.com/VW3st/halo.git@v1.1.0

# 2. fetch the Kokoro TTS model (~200 MB)
halo download-models

# 3. start the router LLM
ollama pull qwen2.5:1.5b-instruct

# 4. install at least one coding agent
npm install -g @anthropic-ai/claude-code
claude login

npm install -g @openai/codex
codex login

# 5. verify your environment
halo doctor

# 6. go
halo

Windows note: for GPU acceleration, also install pip install halo-voice[gpu-windows] — pulls the NVIDIA cuBLAS + cuDNN wheels that faster-whisper needs. On Mac / Linux, faster-whisper falls back to CPU automatically.
